
# Galeri Karya & Inovasi Siswa
## SMK Plus Umar Zahid

Website ini merupakan galeri digital untuk menampilkan
karya, kreativitas, dan inovasi peserta didik SMK Plus
Umar Zahid.

### Fitur Website
- Beranda galeri sekolah
- Pencarian karya siswa
- Filter berdasarkan kelas dan mata pelajaran
- Formulir unggah karya
- Informasi pengembang website

### Teknologi
- HTML
- CSS
- JavaScript

### Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Pastikan file index.html tersedia.
3. Jalankan index.html menggunakan Live Server.

### Struktur Folder
- index.html : halaman utama
- css/style.css : pengaturan tampilan
- js/script.js : fungsi interaktif website
- assets/ : logo dan gambar pendukung
